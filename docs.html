Documentation

Build Roblox games with an agent that pays its own way.

This page follows the public studspad docs, including the read API at /api/stats. It is not the studspad.app site. Live numbers below are read from their public endpoint.

Overview

A launch turns a prompt into a token. Part of every trade’s creator fee goes to an agent wallet. Each time that wallet earns 0.005 SOL, it writes a Luau script, checks that it compiles, and publishes the place.

PromptLocked after launch. 40–600 characters.
Fees25–100% of creator fees routed to the agent.
BuildsLuau scripts, then a place file.

Quickstart

  1. Connect Phantom or Solflare. You pay network fees plus 0.01 SOL of agent fuel.
  2. Name, ticker, genre, cover, and a 40–600 character prompt.
  3. Pick the agent share. Their default is 50% agent, 50% launcher.
  4. Sign once. Token, fee split, and optional first buy are one approval.
  5. Watch fees, the next build, and every script on the server page.

Fee routing

The split is written into pump.fun’s fee-sharing config. Two shareholders: launcher and agent wallet. The agent share is 25% to 100%.

Launcher50% defaultClaimable creator fee.
Agent wallet50% defaultNetwork fees, then a build every 0.005 SOL.

Of every fee the agent receives, 20% buys and burns EHwZjQen7jjfU3SVSHrpkWZCGqRRyTYq3gWbHQXojB3A through Jupiter. 80% stays for AI credits and builds. Amounts under 0.002 SOL wait for the next cycle. Your requested pad rule was 50% coding, 25% creator, 25% buyback. That is a different split from the one in their docs.

Agent cycle

  1. Collect pending creator fees.
  2. If the agent earned 0.005 SOL since the last build, start one.
  3. Write the next script from the prompt and earlier builds.
  4. Compile it. A failing build gets one repair.
  5. Pack the scripts into a place and publish.

Anyone can wake an agent with POST /api/servers/:mint/tick. The 10 minute cooldown still applies.

Launch API

POST/api/launch/prepare

Multipart form: image file plus a data JSON field. Returns unsigned transactions. The wallet signs. The server never holds keys.

{
  "mint": "LAVA…pump",
  "agentWallet": "AgNt…9xQe",
  "lastValidBlockHeight": 318204551,
  "txs": ["AQAAAA…", "AQAAAA…"],
  "roles": ["create", "share"]
}

POST/api/launch/confirm

JSON with mint, signed txs, and lastValidBlockHeight. An instruction that differs from prepare is rejected with 422.
